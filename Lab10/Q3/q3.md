Maximum Component Weight with Size Constraint
1. Problem Statement
Given an undirected graph, each vertex v has a weight w[v]. Edges are added one by one. After every edge addition, find the maximum total vertex weight among all connected components whose number of vertices does not exceed a threshold K.
For a component C:
- Component size: number of vertices in C.
- Component weight: sum of the weights of all vertices in C.
- Eligibility: the component is considered only if its size is at most K.
The required result after each operation is the maximum component weight among all eligible components. If K = 0, no non-empty component is eligible.
2. Approach: Disjoint Set Union (DSU)
Use a Disjoint Set Union (DSU) data structure, also known as Union-Find, to maintain connected components as edges arrive.
For each component, maintain:
- Parent: identifies the representative of the component.
- Size: number of vertices in the component.
- Sum: total weight of all vertices in the component.
The DSU uses path compression to speed up representative searches and union by size to keep its trees shallow.
3. Algorithm
Initialization
1. Treat every vertex as a separate component.
2. Set each vertex as its own parent.
3. Initialize each component's size to 1.
4. Initialize each component's total weight to that vertex's weight.
Processing each incoming edge (u, v)
1. Find the representatives of u and v.
2. If both vertices already have the same representative, they are already connected, so no merge is needed.
3. Otherwise, merge the two components using union by size:
   - Attach the smaller component to the larger component.
   - Add their sizes.
   - Add their total weights.
4. After processing the edge, examine all component representatives.
5. Consider only components whose size is at most K.
6. Among those components, find and output the maximum total weight.
The implementation scans all vertices after each edge. This makes the solution straightforward to understand and validate.
4. Why the Approach Works
Initially, each vertex forms a separate connected component, so its size is 1 and its component weight is its own vertex weight.
When an edge connects vertices from different components, those components become one component. DSU merges them, and the new size and weight are calculated by adding the values of both previous components. If the endpoints are already in the same component, the graph's connected components do not change.
After every edge operation, scanning the DSU representatives identifies all current components. Filtering by size <= K and selecting the maximum component weight therefore gives the required answer.
5. Example
Suppose there are five vertices, the size limit is K = 2, and their weights are:
- Vertex 1: 4
- Vertex 2: 7
- Vertex 3: 2
- Vertex 4: 9
- Vertex 5: 5
The edges arrive in this order: (1, 2), (2, 3), (4, 5).
Edge added	Connected components	Maximum eligible weight
(1, 2)	{1,2}, {3}, {4}, {5}	11
(2, 3)	{1,2,3}, {4}, {5}	9
(4, 5)	{1,2,3}, {4,5}	14


Explanation:
- After (1, 2), component {1,2} has size 2 and weight 4 + 7 = 11.
- After (2, 3), component {1,2,3} has size 3, exceeding K. It is excluded, so the best eligible component is vertex {4} with weight 9.
- After (4, 5), component {4,5} has size 2 and weight 9 + 5 = 14.
Output: 11, 9, 14
6. Complexity Analysis
Let V be the number of vertices and E the number of edge additions.
- Initialization: O(V)
- DSU merge per edge: amortized O(α(V))
- Scanning components after each edge: O(V)
- Total time complexity: O(V + E(V + α(V))), commonly simplified to O(V + EV)
- Auxiliary space complexity: O(V)
Here, α(V) is the inverse Ackermann function, which grows extremely slowly and is effectively constant for practical input sizes.
The space complexity is O(V) because the parent, size, and component-weight arrays store a constant amount of information per vertex. The full graph does not need to be stored.
7. Conclusion
DSU efficiently maintains connected components, their sizes, and their total vertex weights as edges arrive. After each edge, scanning the components and checking the size constraint finds the maximum eligible component weight.
This straightforward implementation uses O(V) auxiliary space and O(V + EV) time, making it suitable for validating the algorithm and understanding dynamic connectivity.
