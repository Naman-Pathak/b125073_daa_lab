# Reverse Time-Step DSU Application

## 1. Problem Statement

Given an undirected graph with `V` vertices and `E` edges, each vertex has a weight. Vertices are deleted one by one in a specified order.

After every deletion, find the **maximum sum of vertex weights among all remaining connected components**. If no vertices remain, there are no connected components.

## 2. Approach: Reverse-Time DSU

Deleting a vertex can split a connected component into multiple components, making the problem difficult to handle directly.

To simplify it, process the deletions in reverse order using a **Disjoint Set Union (DSU)** data structure.

The main idea is:

- Start with all vertices inactive.
- Add vertices back in the reverse of the deletion order.
- When a vertex is activated, connect it to its active neighbors using DSU.
- Maintain the total weight of every connected component.
- Record the maximum component sum at each step.
- Use these results to obtain the answers for the original deletion order.

DSU efficiently merges connected components using path compression and union by size.

## 3. Data Structures Used

- **Adjacency list:** Stores the neighbors of each vertex.
- **Active array:** Tracks whether a vertex has been activated.
- **Parent array:** Stores the DSU parent of each vertex.
- **Size array:** Helps merge smaller DSU trees into larger ones.
- **Component-sum array:** Stores the total weight of each component.
- **Answer array:** Stores results in the required order.

## 4. Algorithm

1. Read the number of vertices and edges.
2. Read the weight of every vertex.
3. Build the graph using an adjacency list.
4. Read the vertex deletion order.
5. Initialize all vertices as inactive.
6. Process the deletion order backward:
   - Activate the current vertex.
   - Initialize its component sum with its own weight.
   - For each active neighbor, merge their components if they are different.
   - Update the component sum after every merge.
   - Find and record the maximum component sum among active components.
7. Arrange the recorded answers according to the original deletion order.
8. Print the maximum sum after each deletion. If no components remain, print `No components`.

## 5. Example

### Input

    5 4
    4 7 2 9 5
    1 2
    2 3
    3 4
    4 5
    1 3 2 4 5

The graph is a path:

`1 — 2 — 3 — 4 — 5`

Vertex weights:

- Vertex 1: 4
- Vertex 2: 7
- Vertex 3: 2
- Vertex 4: 9
- Vertex 5: 5

Deletion order: `1, 3, 2, 4, 5`.

### Explanation

| Deleted vertex | Remaining components | Maximum sum |
|---|---|---:|
| 1 | `{2, 3, 4, 5}` | 23 |
| 3 | `{2}`, `{4, 5}` | 14 |
| 2 | `{4, 5}` | 14 |
| 4 | `{5}` | 5 |
| 5 | No components remain | No components |

### Output

    23
    14
    14
    5
    No components

## 6. Why the Approach Works

When a vertex is added back, it can connect only to its active neighbors. DSU merges the connected components reached through those neighbors and combines their weight sums.

Therefore, each DSU component represents a connected component of the currently active graph. Processing the vertices in reverse deletion order allows the algorithm to reconstruct the graph state after every original deletion.

## 7. Complexity Analysis

Let `V` be the number of vertices and `E` be the number of edges.

### Time Complexity

- Building the adjacency list: `O(V + E)`
- Activating vertices and processing edges with DSU: `O((V + E) α(V))`
- Scanning all vertices to find the maximum component sum after every activation: `O(V²)`

Here, `α(V)` is the inverse Ackermann function, which grows extremely slowly and is practically constant.

**Total time complexity:**

`O(V² + (V + E) α(V))`

The quadratic term occurs because the described implementation scans all vertices to find the maximum component sum at each step.

### Space Complexity

The adjacency list, DSU arrays, active flags, and answer array require:

**`O(V + E)`**

## 8. Conclusion

Reverse-time processing makes vertex deletion easier to handle by turning deletions into additions. Using DSU to merge components and maintain their weight sums allows the algorithm to determine the maximum connected-component weight after each deletion.
