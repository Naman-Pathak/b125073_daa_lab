Dynamic Connected Components in a Grid
1. Problem Statement
Given an R × C grid that is initially filled with water, land cells are added one by one at positions (r, c).
After each operation, output the current number of islands. An island is a group of land cells connected through the four directions: up, down, left, and right. Diagonal connections do not count.
The grid starts with zero islands. Adding a land cell may create a new island or connect two or more existing islands.
2. Approach: Disjoint Set Union (DSU)
Use a Disjoint Set Union (DSU) data structure, also called Union-Find, to maintain connected components as land cells are added.
Instead of searching the entire grid after every operation, DSU keeps track of which land cells belong to the same island.
Coordinate Flattening
A two-dimensional cell (r, c) is converted into a one-dimensional index:
index = r × C + c
This allows each cell to be stored and managed in simple one-dimensional DSU arrays.
Information Maintained
- Parent: Stores the parent of each cell in the DSU forest. A water cell is marked as inactive.
- Size: Stores the size of each component, used for union by size.
- Island count: Tracks the current number of connected land components.
The algorithm uses path compression in find and union by size in unite to make DSU operations efficient.
3. Algorithm
For each land-addition operation (r, c):
1. Check the position: If it is outside the grid, treat it as invalid. A valid input is assumed for the normal problem.
2. Check for duplicate land: If the cell is already land, do not change the island count; output the current count.
3. Create a new island: Mark the cell as land and initialize it as its own DSU component. Increase the island count by one.
4. Examine four neighbors: Check the cells above, below, to the left, and to the right, making sure each neighbor lies inside the grid.
5. Merge adjacent islands: For every neighboring land cell, find the representatives of both cells. If the representatives differ, merge the components and decrease the island count by one. If they are already in the same component, do not change the count.
6. Output the count: After checking all four neighbors, output the current number of islands.
4. Why the Approach Works
When a water cell becomes land, it initially forms one new island, so the count increases by one.
Each neighboring land cell may belong to a separate island. Whenever DSU merges two previously separate components, those two islands become one, so the count decreases by one. If two cells already belong to the same component, merging them again would not change the number of islands.
Therefore, after processing the new cell and all four neighbors, the maintained count equals the actual number of connected land components.
5. Example
Consider a 3 × 3 grid and these land additions:
(0,0), (0,1), (1,2), (2,1), (1,1), (0,2)
The island count after each operation is:
Operation	Position	Explanation	Island count
1	(0,0)	First land cell creates an island	1
2	(0,1)	Joins the first island	1
3	(1,2)	Creates a separate island	2
4	(2,1)	Creates another separate island	3
5	(1,1)	Connects the three islands	1
6	(0,2)	Joins the existing island	1


Output: 1 1 2 3 1 1
Coordinates in this example are zero-based: rows range from 0 to R-1, and columns range from 0 to C-1.
6. Complexity Analysis
Let N = R × C be the total number of grid cells and k be the number of land-addition operations.
- Initialization: O(RC)
- Processing one operation: amortized O(α(RC)), because each operation checks at most four neighbors and performs a constant number of DSU operations.
- Total time complexity: O(RC + k α(RC))
- Auxiliary space complexity: O(RC)
Here, α(N) is the inverse Ackermann function, which grows extremely slowly and is effectively constant for practical input sizes.
The space complexity is O(RC) because the DSU parent and size arrays store information for every possible grid cell.
7. Conclusion
DSU efficiently maintains dynamic connected components in a grid. When a land cell is added, the algorithm creates a new component and merges it with any neighboring land components. The island count is updated immediately after each operation without traversing the entire grid again.
The resulting time complexity is O(RC + k α(RC)), with O(RC) auxiliary space.
