Application of Sorting-I: Sorting Items by Colour

Problem Statement

Assume that we are given n pairs of items as input, where:

The first item is a number.

The second item is one of three colours: Red, Blue, or Yellow.

The items are already sorted by number.

Give an O(n) algorithm to sort the items by colour such that:

All Red items come first.

All Blue items come next.

All Yellow items come last.

The numbers belonging to each identical colour remain sorted.

Also, choose a suitable input representation and write a C program to validate the algorithm.

Example

Input

(1, B)
(2, R)
(3, Y)
(4, R)
(5, B)
(6, Y)
(7, R)

The numbers are already sorted:

1, 2, 3, 4, 5, 6, 7

Required Output

(2, R) (4, R) (7, R) (1, B) (5, B) (3, Y) (6, Y)

Notice that:

All Red items appear first.

All Blue items appear second.

All Yellow items appear last.

Red numbers 2, 4, 7 are still sorted.

Blue numbers 1, 5 are still sorted.

Yellow numbers 3, 6 are still sorted.

Approach

Since the input is already sorted by number, we do not need to sort the numbers again.

We simply scan the array three times:

Pass 1 — Red

Scan the entire array from left to right and output every item whose colour is R.

Pass 2 — Blue

Scan the array again and output every item whose colour is B.

Pass 3 — Yellow

Scan the array one more time and output every item whose colour is Y.

Because every scan goes from left to right, the numbers belonging to the same colour remain in their original sorted order.

Why Does It Work?

Suppose the Red items in the original array are:

(2, R)
(4, R)
(7, R)

Because the entire input is sorted by number, the Red numbers must already appear as:

2 < 4 < 7

When we scan from left to right, we output them in exactly this order:

(2, R) (4, R) (7, R)

Therefore, the numbers of identical colours remain sorted.

The same reasoning applies to Blue and Yellow.

Algorithm

1. Scan the array from left to right.
2. Print/copy every Red item.
3. Scan the array again.
4. Print/copy every Blue item.
5. Scan the array again.
6. Print/copy every Yellow item.

Complexity Analysis

There are three complete scans of the array.

First scan  → O(n)
Second scan → O(n)
Third scan  → O(n)

Therefore:

[
T(n) = O(n) + O(n) + O(n)
]

[
T(n) = O(3n)
]

Ignoring the constant factor:

[
oxed{T(n) = O(n)}
]

Space Complexity

Using an array to store the input:

[
oxed{O(n)}
]

C Implementation

A struct is a suitable representation because each item contains a number and a colour.

#include <stdio.h>

typedef struct {
    int number;
    char colour;
} Item;

int main() {
    int n;

    printf("Enter number of items: ");
    scanf("%d", &n);

    Item a[n];

    printf("Enter number and colour (R/B/Y):\n");

    for (int i = 0; i < n; i++) {
        scanf("%d %c", &a[i].number, &a[i].colour);
    }

    printf("\nSorted by colour:\n");

    // First: Red
    for (int i = 0; i < n; i++) {
        if (a[i].colour == 'R') {
            printf("(%d, R) ", a[i].number);
        }
    }

    // Second: Blue
    for (int i = 0; i < n; i++) {
        if (a[i].colour == 'B') {
            printf("(%d, B) ", a[i].number);
        }
    }

    // Third: Yellow
    for (int i = 0; i < n; i++) {
        if (a[i].colour == 'Y') {
            printf("(%d, Y) ", a[i].number);
        }
    }

    return 0;
}

Sample Run

Input

Enter number of items: 5
Enter number and colour (R/B/Y):
1 B
2 R
3 Y
4 R
5 B
Output

Sorted by colour:
(2, R) (4, R) (1, B) (5, B) (3, Y)

Key Idea

The important observation is:

The input is already sorted by number, so we only need to group the items according to colour.

Scanning from left to right preserves the relative order of the numbers within each colour.

Thus, we can achieve the required sorting in:

[
oxed{O(n)}
]

without using a conventional sorting algorithm
