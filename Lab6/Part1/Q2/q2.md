## Question 2: 0/1 Knapsack Problem Using Dynamic Programming

### Problem Statement

Implement the 0/1 Knapsack problem using Dynamic Programming.

Given a set of items, where each item has a weight and a profit, and a knapsack with a fixed capacity, determine the maximum profit that can be obtained without exceeding the capacity of the knapsack.

### Introduction

The Knapsack problem is an optimization problem in which we have a limited-capacity bag and a collection of items.

Each item has:

- A weight
- A profit or value

The objective is to select items such that the total weight does not exceed the capacity of the knapsack and the total profit is maximum.

In the 0/1 Knapsack problem, every item has only two possible choices:

- 0 → Do not select the item
- 1 → Select the item

An item cannot be selected more than once.

### Dynamic Programming Approach

Dynamic Programming is used to solve the 0/1 Knapsack problem by breaking it into smaller subproblems.

A two-dimensional DP table is used.

Each entry in the table represents the maximum profit that can be obtained using a certain number of items for a particular knapsack capacity.

Let:

dp[i][w]

represent the maximum profit that can be obtained using the first i items when the available capacity is w.

### Working

For every item, there are two possibilities.

#### 1. Item is not selected

If the current item is not selected, the maximum profit remains the same as the maximum profit obtained using the previous items.

Therefore, the result is taken from the previous row of the DP table.

#### 2. Item is selected

If the weight of the current item is less than or equal to the available capacity, the item can be selected.

The profit obtained is:

Current item's profit + maximum profit obtainable using the remaining capacity and previous items.

The algorithm compares the profit obtained by selecting the item with the profit obtained by not selecting it.

The larger value is stored in the DP table.

### Recurrence Relation

If the current item's weight is less than or equal to the current capacity:

dp[i][w] = max(
    dp[i-1][w],
    profit[i] + dp[i-1][w-weight[i]]
)

If the current item's weight is greater than the available capacity:

dp[i][w] = dp[i-1][w]

The use of i-1 when selecting an item ensures that the same item cannot be selected again. This is what makes the problem a 0/1 Knapsack problem.

### Initial Conditions

If there are no items, the maximum profit is zero.

Similarly, if the capacity of the knapsack is zero, no item can be selected, so the maximum profit is also zero.

Therefore:

dp[0][w] = 0

and

dp[i][0] = 0

### Example

Consider three items:

| Item | Weight | Profit |
|------|--------|--------|
| 1 | 10 | 60 |
| 2 | 20 | 100 |
| 3 | 30 | 120 |

Knapsack capacity = 50

Possible useful selection:

Item 2 + Item 3

Total weight:

20 + 30 = 50

Total profit:

100 + 120 = 220

Therefore, the maximum profit is:

220

### Time Complexity

The DP table contains n × W states, where:

- n = number of items
- W = capacity of the knapsack

Each state requires constant time to calculate.

Therefore, the time complexity is:

O(nW)

### Space Complexity

A two-dimensional DP table of size approximately n × W is used.

Therefore, the space complexity is:

O(nW)

### Advantages of Dynamic Programming

- Avoids repeated calculations.
- Provides an efficient solution compared to the basic recursive approach.
- Clearly considers both possibilities of selecting or not selecting each item.
- Guarantees the maximum possible profit for the given capacity.

### Conclusion

The 0/1 Knapsack problem can be efficiently solved using Dynamic Programming by considering each item and each possible capacity.

For every item, the algorithm decides whether selecting the item or excluding it gives a better profit. By storing the results of smaller subproblems in a DP table, repeated calculations are avoided.

The resulting maximum value represents the maximum profit that can be obtained without exceeding the knapsack capacity.
