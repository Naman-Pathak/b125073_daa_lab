## Question 3: Longest Common Subsequence (LCS) Using Dynamic Programming

### Problem Statement

Implement the Longest Common Subsequence (LCS) algorithm using Dynamic Programming.

Given two strings, find the length of their longest common subsequence and display the actual subsequence.

### Introduction

A subsequence is a sequence that can be obtained from a string by deleting zero or more characters without changing the relative order of the remaining characters.

For example, consider the string:

ABCDEF

Some of its subsequences are:

- ACE
- BDF
- ABF
- ABC

However, ECA is not a subsequence because the order of the characters has been changed.

A Longest Common Subsequence is the longest subsequence that is common to both given strings.

### Dynamic Programming Approach

The LCS problem can be solved efficiently using Dynamic Programming because the problem can be divided into smaller subproblems.

A two-dimensional DP table is used.

Let:

dp[i][j]

represent the length of the LCS between:

- The first i characters of the first string
- The first j characters of the second string

The table is filled by comparing characters from the two strings.

### Working

For every pair of characters, there are two main cases.

#### Case 1: Characters are Equal

If the current characters of both strings are equal, that character can be included in the common subsequence.

Therefore:

dp[i][j] = dp[i-1][j-1] + 1

The value from the diagonally previous cell is used because both current characters are included in the subsequence.

#### Case 2: Characters are Different

If the current characters are different, they cannot both be included at the same position.

There are two possibilities:

- Exclude the current character from the first string.
- Exclude the current character from the second string.

Therefore, the larger of the two possible LCS lengths is selected:

dp[i][j] = max(dp[i-1][j], dp[i][j-1])

### Initial Conditions

If either string has zero characters, there cannot be any common subsequence.

Therefore:

dp[0][j] = 0

and

dp[i][0] = 0

This forms the first row and first column of the DP table.

### Example

Consider the two strings:

First string:

ABCBDAB

Second string:

BDCABA

One possible Longest Common Subsequence is:

BCBA

Its length is:

4

There can be more than one valid LCS for some pairs of strings. Therefore, different correct implementations may sometimes display different subsequences having the same maximum length.

### Finding the Actual LCS

The DP table initially gives only the length of the LCS.

To obtain the actual subsequence, the table is traced backwards starting from the bottom-right cell.

If the current characters are equal, that character is part of the LCS, so it is included in the result and both indices are moved diagonally upward.

If the characters are different, the algorithm moves toward the neighboring cell having the larger LCS value.

This process continues until the beginning of either string is reached.

Since the characters are found from the end toward the beginning, they are stored in reverse order and then displayed in the correct order.

### Important Observation

The LCS is a subsequence, not necessarily a substring.

A substring must contain consecutive characters, whereas a subsequence does not require the characters to be consecutive.

For example, in:

ABCDEF

ACE is a valid subsequence because the characters occur in the same order, even though they are not adjacent.

### Time Complexity

If the lengths of the two strings are:

- m = length of the first string
- n = length of the second string

The DP table contains approximately m × n entries.

Each entry takes constant time to calculate.

Therefore, the time complexity is:

O(mn)

### Space Complexity

A two-dimensional DP table of size approximately m × n is used.

Therefore, the space complexity is:

O(mn)

### Advantages of Dynamic Programming

- Avoids repeated calculations.
- Efficiently finds the length of the LCS.
- Can also be used to reconstruct the actual LCS.
- Provides an optimal solution for the LCS problem.
- The DP table makes the relationship between smaller and larger subproblems clear.

### Conclusion

The Longest Common Subsequence problem can be efficiently solved using Dynamic Programming by storing the LCS lengths of smaller portions of the two strings.

When the current characters are equal, the diagonal value is increased by one. When they are different, the maximum value from the upper or left cell is selected.

After constructing the DP table, it can be traced backwards to obtain an actual longest common subsequence.

The algorithm has a time complexity of O(mn) and a space complexity of O(mn).
