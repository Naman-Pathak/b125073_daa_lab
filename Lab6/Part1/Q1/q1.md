## Question 1: Fibonacci Number Using Dynamic Programming

### Problem Statement

Write a program to find the nth Fibonacci number using Dynamic Programming.

### Introduction

The Fibonacci sequence is a sequence of numbers in which each number is obtained by adding the previous two numbers.

The sequence starts with:

0, 1, 1, 2, 3, 5, 8, 13, ...

The Fibonacci relation is:

F(n) = F(n-1) + F(n-2)

The base cases are:

F(0) = 0

F(1) = 1

### Dynamic Programming Approach

Dynamic Programming is used to avoid calculating the same subproblems repeatedly.

In the Fibonacci problem, every Fibonacci number depends on the two previous Fibonacci numbers. If we use a simple recursive approach, many Fibonacci values are calculated multiple times.

To avoid this repeated calculation, Dynamic Programming stores the Fibonacci values that have already been calculated in an array.

The array stores:

- The 0th Fibonacci number at the first position.
- The 1st Fibonacci number at the second position.
- Every subsequent Fibonacci number is calculated using the two previously stored values.

Thus, when calculating F(n), the values of F(n-1) and F(n-2) are already available.

### Working

The algorithm first handles the base cases:

- If n is 0, the answer is 0.
- If n is 1, the answer is 1.

For values greater than 1, the Fibonacci values are calculated one by one from the beginning.

For every position i:

F(i) = F(i-1) + F(i-2)

The calculated value is stored so that it can be used later.

After all values up to n have been calculated, the value stored at position n represents the nth Fibonacci number.

### Example

Consider n = 7.

The Fibonacci values are calculated as follows:

F(0) = 0  
F(1) = 1  
F(2) = 1  
F(3) = 2  
F(4) = 3  
F(5) = 5  
F(6) = 8  
F(7) = 13

Therefore, the 7th Fibonacci number is:

13

### Time Complexity

The algorithm calculates each Fibonacci number only once.

Therefore, the time complexity is:

O(n)

### Space Complexity

An array is used to store the Fibonacci values from F(0) to F(n).

Therefore, the space complexity is:

O(n)

### Advantages of Dynamic Programming

- Avoids repeated calculations.
- Improves the efficiency compared to the basic recursive Fibonacci approach.
- The previously calculated results can be directly reused.
- The approach is simple and easy to implement.

### Conclusion

The nth Fibonacci number can be efficiently calculated using Dynamic Programming by storing previously calculated Fibonacci values. This eliminates repeated calculations and reduces the time complexity to O(n), while using O(n) additional space.
