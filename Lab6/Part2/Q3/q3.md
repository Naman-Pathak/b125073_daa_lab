# Q3 – Convolution of Two Vectors Using Divide and Conquer

## Problem Overview

The convolution of vectors `A` and `B` produces a new vector `C` whose elements are calculated using:

`C[k] = Σ A[j] B[k-j]`

The lengths of `A` and `B` are `m` and `n`, respectively, and the problem assumes:

`n ≥ m`

The required goal is an **O(n log n)** divide-and-conquer algorithm.

## Why Direct Convolution Is Not Enough

A direct implementation calculates every output element by summing products of input elements. This requires roughly `m × n` operations.

Since the requirement is `O(n log n)`, direct convolution does not meet the requested bound in general.

## FFT-Based Solution

The solution uses the Fast Fourier Transform (FFT).

The convolution theorem states that convolution in the original domain becomes element-wise multiplication in the frequency domain.

The steps are:

1. Determine the required convolution length:

   `m + n - 1`

2. Pad both vectors with zeros until their lengths reach a suitable power of two.

3. Apply FFT to vector `A`.

4. Apply FFT to vector `B`.

5. Multiply the corresponding transformed values:

   `F[i] = FFT(A)[i] × FFT(B)[i]`

6. Apply the inverse FFT to the resulting vector.

7. The first `m + n - 1` values form the convolution vector.

## Divide-and-Conquer Nature of FFT

FFT recursively divides a problem into smaller even-indexed and odd-indexed subproblems. The recurrence is:

`T(N) = 2T(N/2) + O(N)`

Therefore:

`T(N) = O(N log N)`

## Why the Complexity Is O(n log n)

There are two forward FFTs and one inverse FFT. Each takes:

`O(N log N)`

The element-wise multiplication takes:

`O(N)`

So the total complexity is:

`O(N log N) + O(N log N) + O(N) + O(N log N)`

which simplifies to:

**O(N log N)**

Because `n ≥ m` and the required convolution length is `m + n - 1`, this length is at most proportional to `n`. The zero-padded FFT size `N` is therefore also `O(n)`.

Hence the required complexity becomes:

**O(n log n)**

## Correctness Idea

The convolution theorem guarantees that multiplying the Fourier transforms of the two input vectors gives the Fourier transform of their convolution. Applying the inverse FFT therefore recovers the required convolution values.

## Complexity Summary

| Step | Complexity |
|---|---:|
| FFT of A | O(n log n) |
| FFT of B | O(n log n) |
| Point-wise multiplication | O(n) |
| Inverse FFT | O(n log n) |
| **Total** | **O(n log n)** |

## Conclusion

FFT converts convolution from a direct quadratic-style computation into an efficient frequency-domain operation. The divide-and-conquer structure of FFT provides the required **O(n log n)** running time.
