# Longest Common Subsequence (LCS)

## 1. Problem Statement

Given two sequences:

```text
X = {x1, x2, ..., xm}
Y = {y1, y2, ..., yn}
```

find:

1. The **length of their Longest Common Subsequence (LCS)**.
2. The **actual LCS string**.

A subsequence is obtained by deleting zero or more elements from a sequence without changing the relative order of the remaining elements.

The elements do **not** need to be adjacent.

---

# 2. Example

Consider:

```text
X = ABCBDAB
Y = BDCABA
```

One possible LCS is:

```text
BCBA
```

Therefore:

```text
Length of LCS = 4
```

Another valid LCS is:

```text
BDAB
```

This shows that an LCS is not necessarily unique.

---

# 3. Important Difference Between Substring and Subsequence

A **substring** requires characters to be consecutive.

For example, in:

```text
ABCDE
```

`BCD` is a substring.

A **subsequence** does not require consecutive characters.

For example:

```text
ACE
```

is a subsequence of:

```text
ABCDE
```

because the relative order of `A`, `C`, and `E` is maintained.

---

# 4. Dynamic Programming Approach

The LCS problem can be solved efficiently using **Dynamic Programming**.

Define:

```text
dp[i][j]
```

as:

> The length of the LCS between the first `i` characters of `X` and the first `j` characters of `Y`.

Therefore:

```text
dp[i][j] = LCS(X[0...i-1], Y[0...j-1])
```

The final answer is:

```text
dp[m][n]
```

where:

* `m` = length of `X`
* `n` = length of `Y`
