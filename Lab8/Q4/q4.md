# Longest Increasing Subsequence (LIS)

## 1. Problem Statement

Given an integer array:

```text
A = [a0, a1, a2, ..., an-1]
```

find the **length of the longest subsequence** such that all elements of the subsequence are **strictly increasing**.

A subsequence is obtained by deleting zero or more elements from the original array while maintaining the relative order of the remaining elements.

### Example

Given:

```text
A = [10, 22, 9, 33, 21, 50, 41, 60]
```

One of the longest increasing subsequences is:

```text
10 → 22 → 33 → 50 → 60
```

Its length is:

```text
5
```

Therefore, the answer is:

```text
5
```

---

# 2. Understanding the Problem

There are two important conditions.

## 2.1 It must be a subsequence

The elements must occur in the same order as in the original array.

For example:

```text
A = [10, 22, 9, 33]
```

The following is a valid subsequence:

```text
[10, 22, 33]
```

because the elements occur in the same order.

The elements do not need to be adjacent.

---

## 2.2 It must be strictly increasing

Every element must be greater than the element before it.

For example:

```text
[10, 22, 33]
```

is strictly increasing because:

```text
10 < 22 < 33
```

But:

```text
[10, 22, 22, 33]
```

is not strictly increasing because:

```text
22 < 22
```

is false.

---

# 3. Example

Consider:

```text
A = [10, 22, 9, 33, 21, 50, 41, 60]
```

Some increasing subsequences are:

```text
[10, 22]
[10, 33]
[10, 22, 33]
[10, 22, 33, 50]
[10, 22, 33, 50, 60]
```

The longest one is:

```text
[10, 22, 33, 50, 60]
```

Therefore:

```text
LIS length = 5
```

---

# 4. Why Dynamic Programming?

A simple brute-force approach would generate all possible subsequences.

For an array containing `n` elements, there are:

```text
2^n
```

possible subsequences.

Checking all of them would require exponential time.

Instead, we use **Dynamic Programming**.

The key observation is:

> The longest increasing subsequence ending at the current element can be calculated using the longest increasing subsequences ending at previous smaller elements.

Thus, we solve smaller problems first and reuse their results.

---

# 5. Dynamic Programming State

Define:

```text
dp[i]
```

as:

> The length of the longest strictly increasing subsequence that ends at index `i`.

For example:

```text
A = [10, 22, 9]
```

For `A[0] = 10`, the only possible subsequence is:

```text
[10]
```

Therefore:

```text
dp[0] = 1
```

For `A[1] = 22`:

```text
10 < 22
```

so we can form:

```text
[10, 22]
```

Therefore:

```text
dp[1] = 2
```

For `A[2] = 9`:

```text
10 < 9    → false
22 < 9    → false
```

Therefore:

```text
dp[2] = 1
```

So:

```text
dp = [1, 2, 1]
```

---

# 6. Initialization

Every individual element is itself an increasing subsequence of length `1`.

Therefore:

```text
dp[i] = 1
```

for every `i`.

For example:

```text
A  = [10, 22, 9, 33]

dp = [1,  1,  1,  1]
```

---

# 7. DP Transition

For each element `A[i]`, we check every previous element `A[j]`.

Here:

```text
j < i
```

If:

```text
A[j] < A[i]
```

then `A[i]` can be appended to the increasing subsequence ending at `A[j]`.

Therefore:

```text
dp[i] = max(dp[i], dp[j] + 1)
```

### Recurrence

$$
dp[i] = \max(dp[i], dp[j] + 1)
$$

when:

$$
j < i \quad \text{and} \quad A[j] < A[i]
$$

---

# 8. Complete Algorithm

```text
Algorithm: Longest Increasing Subsequence

Input:
    An integer array A of size n

Output:
    Length of the longest strictly increasing subsequence

1. Create an array dp[n].

2. Initialize every dp[i] = 1.

3. For i = 1 to n-1:

       For j = 0 to i-1:

           If A[j] < A[i]:

               dp[i] = max(dp[i], dp[j] + 1)

4. Find the maximum value in dp[].

5. Return the maximum value.
```

### Step 2: A[1] = 22

Therefore:


### Step 3: A[2] = 9

```text
10 < 9   → false
```

Therefore:

```text

```

### Step 4: A[3] = 33

Check previous elements:

```text
10 < 33   → dp[0] + 1 = 2
22 < 33   → dp[1] + 1 = 3
9 < 33    → dp[2] + 1 = 2
```

Maximum is `3`.

Therefore:

```text

```

Corresponding subsequence:

```text

```

### Step 5: A[4] = 21

Check:

```text
10 < 21   → 2
22 < 21   → false
9 < 21    → 2
33 < 21   → false
```

Therefore:

```text
dp[4] = 2
```

---

### Step 6: A[5] = 50

The best previous increasing subsequence is:

```text
10 → 22 → 33
```

with length `3`.

Since:

```text
33 < 50
```

we get:

```text
dp[5] = 3 + 1
      = 4
```

Subsequence:

```text
10 → 22 → 33 → 50
```

---

### Step 7: A[6] = 41

The best subsequence that can be extended to `41` is:

```text
10 → 22 → 33
```

Therefore:

```text
dp[6] = 4
```

One possible subsequence is:

```text
10 → 22 → 33 → 41
```

### Step 8: A[7] = 60

The best subsequence before `60` is:

```text
10 → 22 → 33 → 50
```

Since:

```text
50 < 60
```

we get:

```text
dp[7] = 4 + 1
      = 5
```

Therefore:

```text
10 → 22 → 33 → 50 → 60
```

# 11. C Implementation

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    int *A = (int *)malloc(n * sizeof(int));
    int *dp = (int *)malloc(n * sizeof(int));

    if (A == NULL || dp == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("Enter the elements:\n");

    for (int i = 0; i < n; i++) {
        scanf("%d", &A[i]);
    }

    /*
        dp[i] represents the length of the
        longest increasing subsequence
        ending at index i.
    */

    // Every element alone has LIS length 1
    for (int i = 0; i < n; i++) {
        dp[i] = 1;
    }

    // Calculate DP values
    for (int i = 1; i < n; i++) {

        for (int j = 0; j < i; j++) {

            if (A[j] < A[i]) {

                if (dp[j] + 1 > dp[i]) {
                    dp[i] = dp[j] + 1;
                }
            }
        }
    }

    // Find the maximum LIS length
    int lis = dp[0];

    for (int i = 1; i < n; i++) {

        if (dp[i] > lis) {
            lis = dp[i];
        }
    }

    printf("\nLength of Longest Increasing Subsequence = %d\n", lis);

    // Free dynamically allocated memory
    free(A);
    free(dp);

    return 0;
}
```

# 14. Correctness Proof

We prove that the algorithm correctly calculates the length of the longest increasing subsequence.

### Base Case

For every element `A[i]`, the subsequence containing only that element is valid.

Therefore:

```text
dp[i] = 1
```

is correct initially.

### Inductive Step

Suppose `A[j] < A[i]`.

If `dp[j]` is the length of the longest increasing subsequence ending at `A[j]`, then we can append `A[i]` to that subsequence.

The resulting subsequence has length:

```text
dp[j] + 1
```

The algorithm checks every `j < i`, so it considers every possible previous element that can precede `A[i]`.

Taking the maximum:

```text
dp[i] = max(dp[i], dp[j] + 1)
```

therefore gives the longest increasing subsequence ending at `i`.

Finally, the overall LIS can end at any index. Therefore:

```text
max(dp[0], dp[1], ..., dp[n-1])
```

is the length of the global longest increasing subsequence.

Hence, the algorithm is correct.

# 15. Complexity Analysis

## Time Complexity

The algorithm contains two nested loops:

```text
for i = 1 to n-1
    for j = 0 to i-1
```

The number of comparisons is:

```text
1 + 2 + 3 + ... + (n - 1)
```

which is:

$$
\frac{n(n-1)}{2}
$$

Therefore:

$$
\boxed{O(n^2)}
$$

### Time Complexity

```text
O(n²)
```

---

## Space Complexity

We use:

```text
A  → O(n)
dp → O(n)
```

Therefore:

$$
\boxed{O(n)}
$$

### Space Complexity

```text
O(n)
```

```text

```

---

Input:

```text
A = [5, 4, 3, 2, 1]
```

No two elements can form an increasing subsequence.

Every element individually forms a subsequence of length `1`.

Output:

```text

```

Input:

```text
A = [1, 2, 2, 3]
```

Since the subsequence must be **strictly** increasing, the two `2`s cannot both be selected.

One LIS is:

```text
1 → 2 → 3
```

Output:

```text
3
```

# 17. LIS vs Maximum Sum Increasing Subsequence

LIS and Maximum Sum Increasing Subsequence (MSIS) use a very similar DP approach, but their objectives are different.

| Feature        | LIS            | MSIS           |
| -------------- | -------------- | -------------- |
| Objective      | Maximum length | Maximum sum    |
| `dp[i]` stores | Length         | Sum            |
| Transition     | `dp[j] + 1`    | `dp[j] + A[i]` |
| Time           | `O(n²)`        | `O(n²)`        |
| Space          | `O(n)`         | `O(n)`         |

For example:

```text
A = [1, 2, 3, 100]
```

### LIS

```text
1 → 2 → 3 → 100
```

Length:

```text
4
```

### MSIS

```text
1 + 2 + 3 + 100 = 106
```

Sum:

```text
106
```

---

# 18. Why This is Dynamic Programming

This problem satisfies the two important properties of Dynamic Programming:

### 1. Optimal Substructure

The optimal solution for a problem can be constructed from optimal solutions of smaller subproblems.

For example, the LIS ending at `33` depends on the best LIS ending at previous elements smaller than `33`.

### 2. Overlapping Subproblems

The same `dp[j]` values are used multiple times when calculating different `dp[i]` values.

Instead of calculating them repeatedly, we store them in the `dp[]` array.

---

# 19. Conclusion

The Longest Increasing Subsequence problem can be efficiently solved using Dynamic Programming.

The main idea is to define:

```text
dp[i] = length of the longest increasing subsequence ending at i
```

For every previous element `A[j]`, if:

```text
A[j] < A[i]
```

then:

```text
dp[i] = max(dp[i], dp[j] + 1)
```

The final answer is:

```text
max(dp[i])
```

For the example:

```text
A = [10, 22, 9, 33, 21, 50, 41, 60]
```

the result is:

```text
LIS = [10, 22, 33, 50, 60]

Length = 5
```

### Final Complexity

```text
Time Complexity  : O(n²)
Space Complexity : O(n)
```

The `O(n²)` Dynamic Programming solution provides a substantial improvement over the exponential brute-force approach.
