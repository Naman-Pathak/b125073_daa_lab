# Minimum Coin Change

## 1. Problem Statement

Given an integer array of coin denominations:

```text
C = {c1, c2, ..., cn}
```

and a target amount `V`, find the **minimum number of coins** required to make the amount `V`.

There is an **infinite supply** of every coin denomination.

If the target amount cannot be formed using the given denominations, return `-1`.

### Example

For:

```text
Coins = {1, 3, 4}
Target = 6
```

Possible ways to make 6:

```text
1 + 1 + 1 + 1 + 1 + 1 = 6 coins
3 + 3 = 2 coins
4 + 1 + 1 = 3 coins
```

Therefore, the answer is:

```text
2
```

---

# 2. Approach

We solve this problem using **Dynamic Programming**.

The main idea is to solve the problem for smaller amounts first and use those answers to find the answer for larger amounts.

Define:

```text
dp[i] = minimum number of coins required to make amount i
```

Our final answer will be:

```text
dp[V]
```

---

# 3. Base Case

To make an amount of `0`, we need `0` coins.

Therefore:

```text
dp[0] = 0
```

For all other amounts, initially assume that they cannot be formed.

```text
dp[i] = INFINITY
```

for:

```text
i = 1, 2, ..., V
```

---

# 4. Recurrence Relation

Suppose we want to calculate `dp[i]`.

We try every coin denomination.

If a coin has value `c` and:

```text
c <= i
```

then we can use that coin.

After taking the coin, the remaining amount is:

```text
i - c
```

The number of coins required will be:

```text
dp[i - c] + 1
```

Therefore:

```text
dp[i] = min(dp[i], dp[i - c] + 1)
```

for every coin `c`.

---

# 5. Example Walkthrough

Consider:

```text
Coins = {1, 3, 4}
V = 6
```

We calculate the DP table from `0` to `6`.

| Amount | Minimum Coins |
| ------ | ------------- |
| 0      | 0             |
| 1      | 1             |
| 2      | 2             |
| 3      | 1             |
| 4      | 1             |
| 5      | 2             |
| 6      | 2             |

Let's understand `dp[6]`.

For coin `1`:

```text
dp[6] = dp[5] + 1
      = 2 + 1
      = 3
```

For coin `3`:

```text
dp[6] = dp[3] + 1
      = 1 + 1
      = 2
```

For coin `4`:

```text
dp[6] = dp[2] + 1
```
