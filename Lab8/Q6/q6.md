# Edit Distance with Traceback Information

## 1. Problem Statement

Given two strings `A` and `B` of lengths `m` and `n`, find the minimum number of operations required to transform string `A` into string `B`.

The allowed operations are:

1. **Insertion** — insert a character.
2. **Deletion** — delete a character.
3. **Substitution** — replace one character with another.

In addition to finding the minimum number of operations, we must also print the **traceback information**, which shows the actual sequence of operations used to transform `A` into `B`.

---

## 2. Example

Consider:

```text
A = kitten
B = sitting
```

One optimal transformation is:

```text
kitten
  ↓
sitten       (substitute k → s)
  ↓
sittin       (substitute e → i)
  ↓
sitting      (insert g)
```

Therefore:

```text
Minimum Edit Distance = 3
```

---

# 3. What is Edit Distance?

Edit distance measures how different two strings are.

For example:

```text
A = cat
B = cut
```

We can transform `cat` into `cut` by substituting:

```text
a → u
```

Therefore:

```text
Edit Distance = 1
```

Another example:

```text
A = abc
B = abcd
```

We only need to insert `d`:

```text
abc → abcd
```

Therefore:

```text
Edit Distance = 1
```

---

# 4. Why Dynamic Programming?

A brute-force solution would try every possible sequence of insertions, deletions, and substitutions.

This produces a very large number of possibilities.

Instead, we use **Dynamic Programming**.

The important observation is:

> The edit distance between two strings can be calculated using the edit distances of their smaller prefixes.

For example, to calculate the edit distance between:

```text
ABC
ABCD
```

we can use the already calculated edit distance between:

```text
AB
ABC
```

and other smaller prefixes.

This gives us **optimal substructure** and allows us to store previously calculated results.

---

# 5. DP Definition

Let:

```text
dp[i][j]
```

represent:

> The minimum number of operations required to transform the first `i` characters of string `A` into the first `j` characters of string `B`.

Therefore:

```text
dp[i][j] = Edit distance between A[0...i-1] and B[0...j-1]
```

The final answer will be:

```text
dp[m][n]
```

where:

```text
m = length of A
n = length of B
```

---

# 6. Base Cases

## 6.1 Transforming an Empty String into B

If `A` is empty:

```text
A = ""
B = "abc"
```

we need three insertions:

```text
Insert a
Insert b
Insert c
```

Therefore:

```text
dp[0][j] = j
```

---

## 6.2 Transforming A into an Empty String

If `B` is empty:

```text
A = "abc"
B = ""
```

we need three deletions:

```text
Delete a
Delete b
Delete c
```

Therefore:

```text
dp[i][0] = i
```

---

# 7. DP Recurrence

Consider the last characters:

```text
A[i-1]
B[j-1]
```

There are two main cases.

## Case 1: Characters are equal

If:

```text
A[i-1] == B[j-1]
```

no operation is required.

Therefore:

```text
dp[i][j] = dp[i-1][j-1]
```

For example:

```text
A = "cat"
B = "car"
```

For the first two characters:

```text
c == c
a == a
```

so no operations are required for those characters.

---

# 8. Case 2: Characters are Different

If:

```text
A[i-1] != B[j-1]
```

we have three choices.

### 8.1 Insertion

Insert `B[j-1]`.

```text
dp[i][j-1] + 1
```

---

### 8.2 Deletion

Delete `A[i-1]`.

```text
dp[i-1][j] + 1
```

---

### 8.3 Substitution

Replace `A[i-1]` with `B[j-1]`.

```text
dp[i-1][j-1] + 1
```

Therefore:

```text
dp[i][j] = 1 + min(
    dp[i-1][j],       // deletion
    dp[i][j-1],       // insertion
    dp[i-1][j-1]      // substitution
)
```

---

# 9. Complete Recurrence

The complete recurrence is:

```text
if A[i-1] == B[j-1]:

    dp[i][j] = dp[i-1][j-1]

else:

    dp[i][j] = 1 + min(
        dp[i-1][j],
        dp[i][j-1],
        dp[i-1][j-1]
    )
```

---

# 10. Example DP Table

Consider:

```text
A = "cat"
B = "cut"
```

The DP table is:

```text
       ""  c  u  t
   ""   0  1  2  3
    c   1  0  1  2
    a   2  1  1  2
    t   3  2  2  1
```

Therefore:

```text
dp[3][3] = 1
```

So:

```text
Edit Distance = 1
```

The operation is:

```text
SUBSTITUTE 'a' → 'u'
```

---

# 11. Traceback

The DP table tells us the minimum cost, but the question also requires the actual operations.

To obtain the operations, we start from:

```text
dp[m][n]
```

and move backwards toward:

```text
dp[0][0]
```

This process is called **traceback**.

---

# 12. Traceback Rules

Suppose we are currently at:

```text
dp[i][j]
```

## Rule 1: Match

If:

```text
A[i-1] == B[j-1]
```

and:

```text
dp[i][j] == dp[i-1][j-1]
```

then:

```text
MATCH
```

Move:

```text
(i, j) → (i-1, j-1)
```

---

## Rule 2: Substitution

If:

```text
dp[i][j] == dp[i-1][j-1] + 1
```

then the operation is:

```text
SUBSTITUTE A[i-1] → B[j-1]
```

Move:

```text
(i, j) → (i-1, j-1)
```

---

## Rule 3: Deletion

If:

```text
dp[i][j] == dp[i-1][j] + 1
```

then:

```text
DELETE A[i-1]
```

Move:

```text
(i, j) → (i-1, j)
```

---

## Rule 4: Insertion

If:

```text
dp[i][j] == dp[i][j-1] + 1
```

then:

```text
INSERT B[j-1]
```

Move:

```text
(i, j) → (i, j-1)
```

Since traceback moves from the end toward the beginning, the operations are stored and then printed in reverse order.

---

# 13. Complete Algorithm

```text
EDIT-DISTANCE(A, B)

1. Let m = length(A)
2. Let n = length(B)

3. Create dp[m+1][n+1]

4. Initialize:
       dp[i][0] = i
       dp[0][j] = j

5. For i = 1 to m:
       For j = 1 to n:

           If A[i-1] == B[j-1]:

               dp[i][j] = dp[i-1][j-1]

           Else:

               dp[i][j] = 1 + min(
                   dp[i-1][j],
                   dp[i][j-1],
                   dp[i-1][j-1]
               )

6. The minimum edit distance is dp[m][n]

7. Start traceback from dp[m][n]

8. While i > 0 or j > 0:

       If characters are equal:
           Record MATCH
           Move diagonally

       Else if substitution gives current value:
           Record SUBSTITUTION
           Move diagonally

       Else if deletion gives current value:
           Record DELETION
           Move up

       Else:
           Record INSERTION
           Move left

9. Reverse the recorded operations.

10. Print the operations.
```

# 14. C Implementation

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX 100

typedef struct {
    char operation[100];
} Operation;

int min3(int a, int b, int c) {
    int minimum = a;

    if (b < minimum)
        minimum = b;

    if (c < minimum)
        minimum = c;

    return minimum;
}

int main() {

    char A[MAX], B[MAX];

    printf("Enter first string: ");
    scanf("%99s", A);

    printf("Enter second string: ");
    scanf("%99s", B);

    int m = strlen(A);
    int n = strlen(B);

    /*
        Allocate DP table dynamically.
        dp[i][j] = minimum edit distance between
        first i characters of A and first j characters of B.
    */

    int **dp = (int **)malloc((m + 1) * sizeof(int *));

    for (int i = 0; i <= m; i++) {
        dp[i] = (int *)malloc((n + 1) * sizeof(int));
    }

    /*
        Base cases
    */

    for (int i = 0; i <= m; i++) {
        dp[i][0] = i;
    }

    for (int j = 0; j <= n; j++) {
        dp[0][j] = j;
    }

    /*
        Fill DP table
    */

    for (int i = 1; i <= m; i++) {

        for (int j = 1; j <= n; j++) {

            if (A[i - 1] == B[j - 1]) {

                // Characters are equal
                dp[i][j] = dp[i - 1][j - 1];

            } else {

                int insertion = dp[i][j - 1];
                int deletion = dp[i - 1][j];
                int substitution = dp[i - 1][j - 1];

                dp[i][j] = 1 + min3(
                    insertion,
                    deletion,
                    substitution
                );
            }
        }
    }

    /*
        Minimum edit distance
    */

    printf("\nMinimum Edit Distance = %d\n", dp[m][n]);

    /*
        TRACEBACK

        Maximum number of operations is m + n.
    */

    Operation *trace =
        (Operation *)malloc((m + n + 1) * sizeof(Operation));

    int count = 0;

    int i = m;
    int j = n;

    while (i > 0 || j > 0) {

        /*
            Case 1: Match
        */

        if (i > 0 &&
            j > 0 &&
            A[i - 1] == B[j - 1] &&
            dp[i][j] == dp[i - 1][j - 1]) {

            sprintf(
                trace[count].operation,
                "MATCH      : '%c'",
                A[i - 1]
            );

            count++;

            i--;
            j--;
        }

        /*
            Case 2: Substitution
        */

        else if (i > 0 &&
                 j > 0 &&
                 dp[i][j] ==
                 dp[i - 1][j - 1] + 1) {

            sprintf(
                trace[count].operation,
                "SUBSTITUTE : '%c' -> '%c'",
                A[i - 1],
                B[j - 1]
            );

            count++;

            i--;
            j--;
        }

        /*
            Case 3: Deletion
        */

        else if (i > 0 &&
                 dp[i][j] ==
                 dp[i - 1][j] + 1) {

            sprintf(
                trace[count].operation,
                "DELETE     : '%c'",
                A[i - 1]
            );

            count++;

            i--;
        }

        /*
            Case 4: Insertion
        */

        else if (j > 0 &&
                 dp[i][j] ==
                 dp[i][j - 1] + 1) {

            sprintf(
                trace[count].operation,
                "INSERT     : '%c'",
                B[j - 1]
            );

            count++;

            j--;
        }
    }

    /*
        Print traceback in forward order.
    */

    printf("\nTraceback:\n");

    for (int k = count - 1; k >= 0; k--) {
        printf("%s\n", trace[k].operation);
    }

    /*
        Print DP table
    */

    printf("\nDP Table:\n\n");

    printf("      ");

    for (int j = 0; j <= n; j++) {

        if (j == 0)
            printf("  0");
        else
            printf("  %c", B[j - 1]);
    }

    printf("\n");

    for (int i = 0; i <= m; i++) {

        if (i == 0)
            printf("  0   ");
        else
            printf("  %c   ", A[i - 1]);

        for (int j = 0; j <= n; j++) {
            printf("%3d", dp[i][j]);
        }

        printf("\n");
    }

    /*
        Free memory
    */

    for (int i = 0; i <= m; i++) {
        free(dp[i]);
    }

    free(dp);
    free(trace);

    return 0;
}
```

# 17. Correctness Proof

We prove that the algorithm produces the minimum edit distance.

## Base Case

For an empty source string:

```text
A = ""
```

transforming it into a string of length `j` requires exactly `j` insertions.

Therefore:

```text
dp[0][j] = j
```

Similarly:

```text
dp[i][0] = i
```

because `i` deletions are required to transform a string of length `i` into an empty string.

---

## Inductive Step

Consider:

```text
dp[i][j]
```

If:

```text
A[i-1] == B[j-1]
```

then the last characters are already equal, so no operation is required:

```text
dp[i][j] = dp[i-1][j-1]
```

If they are different, the final operation must be one of:

```text
Insertion
Deletion
Substitution
```

The algorithm calculates the cost of all three possibilities and selects the minimum:

```text
1 + min(
    dp[i-1][j],
    dp[i][j-1],
    dp[i-1][j-1]
)
```

Therefore, `dp[i][j]` always contains the minimum number of operations needed for the corresponding prefixes.

Hence:

```text
dp[m][n]
```

is the minimum edit distance between `A` and `B`.

The traceback follows the transitions that produced these minimum values, so it reconstructs an optimal sequence of operations.

---

# 18. Complexity Analysis

Let:

```text
m = length of A
n = length of B
```

## Time Complexity

The DP table contains:

```text
(m + 1) × (n + 1)
```

cells.

Each cell requires constant time because we compare at most three possibilities.

Therefore:

```text
Time for DP = O(m × n)
```

The traceback visits at most `m + n` cells:

```text
Time for traceback = O(m + n)
```

Thus, the total complexity is:

$$
\boxed{O(mn)}
$$

---

## Space Complexity

The DP table requires:

```text
(m + 1) × (n + 1)
```

integers.

Therefore:

$$
\boxed{O(mn)}
$$

The traceback array requires at most:

```text
O(m + n)
```

additional space.

Therefore, total space is:

$$
\boxed{O(mn)}
$$

because the DP table dominates.

---

# 19. Complexity Summary

| Component   | Time Complexity | Space Complexity |
| ----------- | --------------: | ---------------: |
| DP Table    |         `O(mn)` |          `O(mn)` |
| Traceback   |        `O(m+n)` |         `O(m+n)` |
| **Overall** |       **O(mn)** |        **O(mn)** |

# 21. Important Points for the Assignment

### DP State

```text
dp[i][j]
```

stores the minimum edit distance between the first `i` characters of `A` and first `j` characters of `B`.

### Base Conditions

```text
dp[i][0] = i
dp[0][j] = j
```

### Transition

If characters match:

```text
dp[i][j] = dp[i-1][j-1]
```

Otherwise:

```text
dp[i][j] = 1 + min(

)
```

### Final Answer

```text
dp[m][n]
```

Start from:

```text

```

```text
dp[0][0]
```

# 22. Conclusion

The Edit Distance problem is a classic application of **Dynamic Programming**.

Instead of checking every possible sequence of operations, we store the optimal solution for every pair of prefixes in a two-dimensional DP table.

The algorithm:

1. Initializes the base cases.
2. Fills the DP table using insertion, deletion, and substitution.
3. Obtains the minimum edit distance from `dp[m][n]`.
4. Performs traceback to recover the actual operations.
5. Prints the sequence of matches, insertions, deletions, and substitutions.

For strings of lengths `m` and `n`:

```text
Time Complexity  = O(mn)
Space Complexity = O(mn)
```

Therefore, the Dynamic Programming approach efficiently solves both parts of the problem: **finding the minimum edit distance and reconstructing its solution through traceback**.
