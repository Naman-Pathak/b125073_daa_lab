# Maximum Sum Increasing Subsequence (MSIS)

## 1. Problem Statement

Given an array of `n` positive integers:

```text
A = [a0, a1, a2, ..., an-1]
```

find the **maximum possible sum of a strictly increasing subsequence**.

A subsequence is obtained by deleting zero or more elements from the array while keeping the relative order of the remaining elements.

A subsequence is **strictly increasing** if:

```text
A[i1] < A[i2] < A[i3] < ... < A[ik]
```

The objective is to maximize:

```text
A[i1] + A[i2] + ... + A[ik]
```

---

## 2. Example

Consider:

```text
A = [1, 101, 2, 3, 100, 4, 5]
```

Some increasing subsequences are:

```text
[1, 101]             → Sum = 102
[1, 2, 3, 100]       → Sum = 106
[1, 2, 3, 4, 5]      → Sum = 15
[1, 2, 3]            → Sum = 6
```

The maximum sum is:

```text
106
```

and the corresponding subsequence is:

```text
[1, 2, 3, 100]
```

Therefore:

```text
Maximum Sum = 106
```

---

# 3. Understanding the Problem

There are two conditions that a valid subsequence must satisfy:

### Condition 1: Subsequence

The elements must appear in the same order as they appear in the original array.

For example:

```text
A = [1, 5, 2, 4]
```

`[1, 2, 4]` is a valid subsequence.

### Condition 2: Strictly Increasing

Every next element must be greater than the previous element.

For example:

```text
[1, 2, 4]
```

is increasing because:

```text
1 < 2 < 4
```

But:

```text
[1, 4, 2]
```

is not increasing.

---

# 4. Why Dynamic Programming?

A brute-force approach would generate all possible subsequences.

For an array of size `n`, there can be:

```text
2^n
```

possible subsequences.

Therefore, checking every subsequence would take exponential time.

Instead, we use **Dynamic Programming**.

The main observation is:

> To find the maximum-sum increasing subsequence ending at an element, we only need to know the best increasing subsequences ending at previous smaller elements.

This allows us to reuse previously calculated results.

---

# 5. DP State

Define:

```text
dp[i]
```

as:

> The maximum sum of a strictly increasing subsequence that ends at index `i`.

For example:

```text
A = [1, 2, 3]
```

Then:

```text
dp[0] = 1
dp[1] = 1 + 2 = 3
dp[2] = 1 + 2 + 3 = 6
```

Therefore:

```text
dp = [1, 3, 6]
```

The final answer is the maximum value in `dp`.

---

# 6. Initialization

Every individual element can form an increasing subsequence containing only itself.

Therefore:

```text
dp[i] = A[i]
```

Initially:

```text
A  = [1, 101, 2, 3, 100, 4, 5]

dp = [1, 101, 2, 3, 100, 4, 5]
```

---

# 7. DP Transition

For every element `A[i]`, check all previous elements `A[j]`.

We can append `A[i]` to a subsequence ending at `j` if:

```text
A[j] < A[i]
```

If this condition is satisfied:

```text
dp[i] = max(dp[i], dp[j] + A[i])
```

### Recurrence

```text
if A[j] < A[i]:

    dp[i] = max(dp[i], dp[j] + A[i])
```

This means:

* `dp[j]` = best sum ending at `A[j]`
* `A[i]` = new element being added
* `dp[j] + A[i]` = new possible sum

# 9. Algorithm

```text
Algorithm: Maximum Sum Increasing Subsequence

Input:
    Array A of n positive integers

Output:
    Maximum sum of a strictly increasing subsequence

1. Create an array dp[n].

2. For every i from 0 to n-1:
       dp[i] = A[i]

3. For i = 1 to n-1:
       For j = 0 to i-1:

           If A[j] < A[i]:
               
               dp[i] = max(dp[i], dp[j] + A[i])

4. Find the maximum value in dp[].

5. Return the maximum value.
```

# 10. C Implementation

```c
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n;

    printf("Enter number of elements: ");
    scanf("%d", &n);

    int *A = (int *)malloc(n * sizeof(int));
    int *dp = (int *)malloc(n * sizeof(int));
    int *parent = (int *)malloc(n * sizeof(int));

    if (A == NULL || dp == NULL || parent == NULL) {
        printf("Memory allocation failed.\n");
        return 1;
    }

    printf("Enter the elements:\n");

    for (int i = 0; i < n; i++) {
        scanf("%d", &A[i]);
    }

    /*
        dp[i] stores the maximum sum of an
        increasing subsequence ending at i.

        parent[i] stores the previous index
        in the selected subsequence.
    */

    for (int i = 0; i < n; i++) {
        dp[i] = A[i];
        parent[i] = -1;
    }

    // Calculate DP values
    for (int i = 1; i < n; i++) {

        for (int j = 0; j < i; j++) {

            if (A[j] < A[i] &&
                dp[j] + A[i] > dp[i]) {

                dp[i] = dp[j] + A[i];
                parent[i] = j;
            }
        }
    }

    // Find maximum sum
    int maxSum = dp[0];
    int maxIndex = 0;

    for (int i = 1; i < n; i++) {

        if (dp[i] > maxSum) {
            maxSum = dp[i];
            maxIndex = i;
        }
    }

    // Reconstruct the subsequence
    int *sequence = (int *)malloc(n * sizeof(int));
    int size = 0;

    int current = maxIndex;

    while (current != -1) {
        sequence[size++] = A[current];
        current = parent[current];
    }

    printf("\nMaximum Sum = %d\n", maxSum);

    printf("Maximum Sum Increasing Subsequence: ");

    for (int i = size - 1; i >= 0; i--) {
        printf("%d ", sequence[i]);
    }

    printf("\n");

    // Free dynamically allocated memory
    free(A);
    free(dp);
    free(parent);
    free(sequence);

    return 0;
}
```

# 13. Reconstruction of the Subsequence

The `dp[]` array gives us the maximum sum, but it does not directly tell us which elements produced that sum.

Therefore, we use another array:

```text
parent[]
```

`parent[i]` stores the index of the previous element in the selected increasing subsequence.

For the example:

```text
A = [1, 101, 2, 3, 100, 4, 5]
```

the important links are:

```text
100 ← 3 ← 2 ← 1
```

Following these links backwards gives:

```text
100 → 3 → 2 → 1
```

Reversing it gives:

```text
1 → 2 → 3 → 100
```

---

# 14. Correctness

We prove that the dynamic programming algorithm gives the maximum possible sum.

### Base Case

For every element `A[i]`, the subsequence containing only that element is valid.

Therefore:

```text
dp[i] = A[i]
```

is correct initially.

### Inductive Step

Assume `dp[j]` correctly represents the maximum sum of an increasing subsequence ending at `A[j]`.

If:

```text
A[j] < A[i]
```

then `A[i]` can be appended to that subsequence.

Its new sum becomes:

```text
dp[j] + A[i]
```

The algorithm checks every valid previous index `j` and chooses the maximum:

```text
dp[i] = max(dp[i], dp[j] + A[i])
```

Therefore, `dp[i]` contains the maximum sum of an increasing subsequence ending at `i`.

Finally, the maximum increasing subsequence can end at any index, so:

```text
max(dp[0], dp[1], ..., dp[n-1])
```

is the global maximum.

Hence, the algorithm is correct.

# 15. Complexity Analysis

## Time Complexity

There are two nested loops:

```text
for i = 1 to n-1
    for j = 0 to i-1
```

The number of comparisons is:

```text
1 + 2 + 3 + ... + (n-1)
```

which equals:

```text
n(n-1) / 2
```

Therefore:

```text
Time Complexity = O(n²)
```

---

## Space Complexity

The algorithm uses:

```text
A        → O(n)
dp       → O(n)
parent   → O(n)
sequence → O(n)
```

Therefore:

```text
Space Complexity = O(n)
```

If only the maximum sum is required and the actual subsequence is not required, the `parent[]` and `sequence[]` arrays can be omitted.

---

# 16. Why Not Brute Force?

A brute-force solution would generate every possible subsequence.

For `n` elements, the number of subsequences is:

```text
2^n
```

Therefore, brute force has exponential complexity.

The dynamic programming solution reduces this to:

```text
O(n²)
```

This makes it much more efficient for larger inputs.

---

# 17. Important Difference: LIS vs MSIS

These two problems are closely related but have different objectives.

### Longest Increasing Subsequence (LIS)

Goal:

```text
Maximize the number of elements
```

Example:

```text
[1, 2, 3, 4]
```

has length `4`.

### Maximum Sum Increasing Subsequence (MSIS)

Goal:

```text
Maximize the sum of elements
```

For example:

```text
A = [1, 2, 3, 100]
```

The sum is:

```text
1 + 2 + 3 + 100 = 106
```

The DP structure is similar, but instead of storing the **length**, we store the **sum**.

# 18. Edge Cases

### Case 1: Single element

```text
A = [10]
```

Answer:

```text
10
```

### Case 2: Already increasing

```text
A = [1, 2, 3, 4, 5]
```

Answer:

```text
15
```

### Case 3: Decreasing array

```text
A = [5, 4, 3, 2, 1]
```

No two elements can form an increasing subsequence.

Therefore, the maximum sum is the largest individual element:

```text
5
```

### Case 4: Duplicate elements

```text
A = [1, 2, 2, 3]
```

Because the subsequence must be **strictly** increasing, both `2`s cannot be selected together.

A valid maximum-sum subsequence is:

```text
1 → 2 → 3
```

with sum:

```text
6
```

---

# 19. Conclusion

The **Maximum Sum Increasing Subsequence** problem can be efficiently solved using Dynamic Programming.

The key idea is:

```text
dp[i] = maximum sum of an increasing subsequence ending at i
```

For every previous index `j`, if:

```text
A[j] < A[i]
```

we can extend the subsequence ending at `j`:

```text
dp[i] = max(dp[i], dp[j] + A[i])
```

Finally:

```text
Answer = max(dp[i])
```

### Final Complexity

```text
Time Complexity  : O(n²)
Space Complexity : O(n)
```

Thus, Dynamic Programming provides a significant improvement over the exponential brute-force approach.
