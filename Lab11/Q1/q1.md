Shortest Path on Parity-Constrained Graphs Using a Queue
1. Problem Statement
Given a directed graph G = (V, E), a source vertex S, and a non-negative penalty C, every edge has a weight of either 0 or 1.

For a path P from S to a vertex v:
- W(P) is the sum of all edge weights on the path.
- k1(P) is the number of weight-1 edges on the path.
The effective cost is:
\[
Cost(P) = W(P) +
\begin{cases}
0, & \text{if } k1(P) \text{ is even}\\
C, & \text{if } k1(P) \text{ is odd}
\end{cases}
\]
The goal is to find the minimum effective cost from S to every vertex. Vertices that cannot be reached from S must be reported as unreachable.
2. Approach
The extra penalty depends on whether the number of weight-1 edges is even or odd. Therefore, tracking only one distance for each vertex is not enough.

We maintain two states for every vertex v:
- dist[v][0]: Minimum sum of edge weights to reach v using an even number of weight-1 edges.
- dist[v][1]: Minimum sum of edge weights to reach v using an odd number of weight-1 edges.
Initially, all distances are infinity, except dist[S][0] = 0, because the source is reached using zero weight-1 edges, and zero is even.
Processing an edge
Suppose the current state is (u, parity) and there is a directed edge u -> v with weight w.
- If w = 0, parity stays the same.
- If w = 1, parity flips.
- The new path weight is dist[u][parity] + w.
The new parity can be calculated as:
newParity = parity ^ w;
If the new path weight is smaller than the current distance for the destination and new parity, update that distance and put the updated state into the queue.

Continue processing states until the queue is empty.
Important note about the queue
This README describes the ordinary FIFO queue with repeated distance relaxation (a label-correcting algorithm). Since distances can improve multiple times, a state may be added to the queue more than once. This method finds the shortest distances for non-negative edge weights, but its worst-case time complexity is O(VE).

For the standard 0-1 BFS algorithm with O(V + E) time complexity, use a double-ended queue (deque): add states reached through weight-0 edges to the front and states reached through weight-1 edges to the back.
3. Final Answer
After the queue processing finishes, calculate the answer for each vertex v:
\[
ans[v] = \min(dist[v][0],\ dist[v][1] + C)
\]
- dist[v][0] has no penalty because the number of weight-1 edges is even.
- dist[v][1] + C includes the penalty because the number of weight-1 edges is odd.
- If both states are infinity, v is unreachable.
4. Graph Representation
Use an adjacency list. Each vertex stores a list of its outgoing edges, and each edge stores:
- Destination vertex
- Edge weight (0 or 1)
- Pointer to the next edge
An adjacency list uses O(V + E) space and is suitable for sparse graphs.
5. Algorithm Steps
1. Read the number of vertices V, number of edges E, source S, and penalty C.
2. Build the adjacency list from the directed edges.
3. Initialize dist[v][0] and dist[v][1] to infinity for every vertex.
4. Set dist[S][0] = 0 and enqueue the source's even-parity state.
5. While the queue is not empty:
   - Remove a state (u, parity).
   - Examine every outgoing edge (u, v, w).
   - Calculate newParity = parity XOR w.
   - Calculate newDist = dist[u][parity] + w.
   - If newDist < dist[v][newParity], update the distance and enqueue the new state.
6. For every vertex, calculate min(dist[v][0], dist[v][1] + C).
7. Print the minimum cost, or Unreachable if both parity states are unreachable.
6. Example
Use the following input:
4 3 0 3
0 1 1
0 2 0
2 3 1
Meaning:
- V = 4 vertices, numbered 0 through 3
- E = 3 directed edges
- Source vertex S = 0
- Penalty C = 3
Edges:
- 0 -> 1 with weight 1
- 0 -> 2 with weight 0
- 2 -> 3 with weight 1
Explanation
- Vertex 0: It is the source. Cost = 0.
- Vertex 1: Path weight is 1; the number of weight-1 edges is odd. Cost = 1 + 3 = 4.
- Vertex 2: Path weight is 0; parity is even. Cost = 0.
- Vertex 3: Path 0 -> 2 -> 3 has total weight 0 + 1 = 1 and odd parity. Cost = 1 + 3 = 4.
Expected output:
Vertex 0: 0
Vertex 1: 4
Vertex 2: 0
Vertex 3: 4
7. Complexity Analysis
Let V be the number of vertices and E be the number of edges in the original graph.

There are two states per vertex, so the expanded state graph has 2V states and at most 2E transitions.

For the ordinary FIFO queue with repeated relaxation:
- Worst-case time complexity: O(VE)
- Space complexity: O(V + E)
The space complexity includes the adjacency list, distance array, and queue. The queue may contain repeated entries for states whose distances improve.

For standard 0-1 BFS using a deque:
- Time complexity: O(V + E)
- Space complexity: O(V + E)
8. Key Insight
The central idea is to split each vertex into even-parity and odd-parity states. This lets the shortest-path algorithm distinguish paths that have the same destination but different penalty outcomes. Apply the penalty only after the minimum edge-weight distance for each parity has been found.
