Candy Distribution Problem
1. Problem Statement
There are n children standing in a line, each with a rating.
The distribution must satisfy these conditions:
1. Every child receives at least one candy.
2. If a child's rating is higher than their immediate left neighbour's rating, they must receive more candies than that neighbour.
3. If a child's rating is higher than their immediate right neighbour's rating, they must receive more candies than that neighbour.
The goal is to find the minimum total number of candies required.
2. Approach: Bi-directional Slope Greedy
Use two arrays:
- rating[]: stores each child's rating.
- candy[]: stores the number of candies assigned to each child.
Initially, give every child one candy. Then make two passes.
Pass 1: Left to Right
For each child i from 1 to n - 1:
- If rating[i] > rating[i - 1], assign candy[i] = candy[i - 1] + 1.
- Otherwise, leave the child with the current candy count (at least one).
This ensures that every child with a higher rating than their left neighbour receives more candies than that neighbour.
Pass 2: Right to Left
For each child i from n - 2 down to 0:
- If rating[i] > rating[i + 1], the current child must receive at least one more candy than the right neighbour.
- Update using candy[i] = max(candy[i], candy[i + 1] + 1).
Taking the maximum preserves the candy requirement established during the first pass while satisfying the right-neighbour constraint.
Finally, add all values in candy[] to obtain the minimum total.
3. Algorithm
1. Read n and the ratings.
2. Initialize candy[i] = 1 for every child.
3. Traverse from left to right and handle increasing adjacent ratings.
4. Traverse from right to left and handle decreasing adjacent ratings.
5. Sum all candy counts and print the total.
6. Free dynamically allocated memory.
4. Example Walkthrough
Input ratings:
1 0 2
Initially:
Ratings:  1 0 2
Candies:  1 1 1
After the left-to-right pass:
Ratings:  1 0 2
Candies:  1 1 2
After the right-to-left pass, the first child's rating is higher than the second child's rating, so the first child needs two candies:
Ratings:  1 0 2
Candies:  2 1 2
Total:
2 + 1 + 2 = 5
Output:
Candies given to each child: 2 1 2
Minimum total candies = 5
5. Why the Greedy Approach Works
Each child starts with the minimum allowed amount: one candy.
The left-to-right pass enforces the condition for children with higher ratings than their left neighbours. The right-to-left pass enforces the condition for children with higher ratings than their right neighbours. It only increases a candy count when necessary and never undoes a condition established by the first pass.
Thus, all neighbour constraints are satisfied, and each candy count is kept as small as possible while satisfying those constraints. The resulting total is minimum.
6. Complexity Analysis
Let n be the number of children.
Time Complexity
- Initializing the arrays: O(n)
- Left-to-right pass: O(n)
- Right-to-left pass: O(n)
- Summing the candy counts: O(n)
The passes are sequential, so the overall time complexity is O(n).
Auxiliary Space Complexity
The algorithm stores ratings and candy counts in two arrays of size n.
Auxiliary space complexity: O(n).
7. Input Representation
The ratings and candy counts are stored in arrays because the children are arranged in a line and neighbour comparisons require access to adjacent indices. Dynamic allocation with malloc() allows the program to handle an input size supplied at runtime. The allocated memory is released with free().
8. Conclusion
The bi-directional slope greedy algorithm solves the Candy Distribution Problem in O(n) time and O(n) auxiliary space. Two directional passes ensure that both neighbour constraints are satisfied with the minimum total number of candies.
