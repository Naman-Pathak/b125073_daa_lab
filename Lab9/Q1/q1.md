# Fractional Knapsack with Deterioration Rate

## 1. Problem Statement

You are given `n` items. Each item has:

- Base value `vi`
- Weight `wi`
- Decay rate `λi`

The value density of an item decreases with time.

The effective value density of item `i` at time `t` is:

\[
D_i(t) = \frac{v_i}{w_i} - \lambda_i t
\]

The knapsack has a maximum capacity `W`.

The objective is to select fractions of items and schedule them in an order such that the total value obtained is maximized.

---

## 2. Approach

We use a **greedy approach**.

Unlike the normal Fractional Knapsack problem, we cannot calculate the density only once because the density changes with time.

At every time `t`:

1. Calculate the effective density of every unused item.
2. Find the item having the **highest effective density**.
3. Add as much of that item as possible to the knapsack.
4. If the complete item fits, take the complete item.
5. Otherwise, take only the required fraction.
6. Increase the time by `1`.
7. Repeat until the knapsack becomes full or no useful item remains.

---

## 3. Effective Density

The normal value density is:

\[
\text{Density}_i = \frac{v_i}{w_i}
\]

Because of deterioration, the density at time `t` becomes:

\[
\boxed{
D_i(t)=\frac{v_i}{w_i}-\lambda_i t
}
\]

For example, if:

```text
Value = 100
Weight = 10
Decay rate = 2
Time = 3
```

Then:

\[
\text{Initial density}=\frac{100}{10}=10
\]

and

\[
\text{Effective density}=10-(2)(3)=4
\]

Therefore, at time `3`, the item provides an effective density of `4`.

---

## 4. Greedy Algorithm

### Algorithm

```text
1. Read n and knapsack capacity W.

2. Read value, weight and decay rate of every item.

3. Set:
      remaining = W
      time = 0
      totalValue = 0

4. While remaining capacity > 0:

      a. Find the unused item having the maximum:

            (value / weight) - decay * time

      b. If maximum density <= 0:
            Stop.

      c. If the complete item fits:

            totalValue += weight * effectiveDensity
            remaining -= weight

         Otherwise:

            fraction = remaining / weight
            totalValue += remaining * effectiveDensity
            remaining = 0

      d. Mark the item as used.

      e. Increase time.

5. Print the total value.
```

---
## 5. Example

Consider:

```text
Number of items = 3
Capacity = 20

Item 1:
Value = 100
Weight = 10
Decay = 1

Item 2:
Value = 120
Weight = 15
Decay = 2

Item 3:
Value = 60
Weight = 5
Decay = 0.5
```

### Time = 0

Effective densities:

\[
D_1(0)=\frac{100}{10}-1(0)=10
\]

\[
D_2(0)=\frac{120}{15}-2(0)=8
\]

\[
D_3(0)=\frac{60}{5}-0.5(0)=12
\]

Highest density is Item 3.

Therefore:

```text
Select Item 3
Weight used = 5
Remaining capacity = 15
```

---

### Time = 1

Now recalculate the densities.

For Item 1:

\[
D_1(1)=10-1=9
\]

For Item 2:

\[
D_2(1)=8-2=6
\]

Item 1 has the highest density.

Therefore:

```text
Select Item 1
Weight used = 10
Remaining capacity = 5
```

---

### Time = 2

Only Item 2 remains.

\[
D_2(2)=8-(2)(2)=4
\]

Its weight is `15`, but only `5` units of capacity remain.

Therefore, take:

\[
\text{fraction}=\frac{5}{15}=\frac{1}{3}
\]

So one-third of Item 2 is selected.

---

## 6. Fraction Calculation

When the entire item does not fit:

\[
\text{Fraction}=
\frac{\text{Remaining Capacity}}{\text{Item Weight}}
\]

The value contributed is:

\[
\text{Value Added}
=
\text{Remaining Capacity}
\times
\text{Effective Density}
\]

For example:

```text
Remaining capacity = 5
Item weight = 15
```

Then:

\[
\text{Fraction}=\frac{5}{15}=\frac13
\]

---

## 7. Why We Recalculate Density

In normal Fractional Knapsack:

\[
D_i=\frac{v_i}{w_i}
\]

remains constant.

Therefore, we can sort the items once.

Here, however:

\[
D_i(t)=\frac{v_i}{w_i}-\lambda_i t
\]

changes as `t` increases.

Therefore, an item that has the highest density at time `0` might not have the highest density at time `1`.

Hence, we must recalculate the effective density at every step.

---

## 8. Complexity Analysis

Suppose there are `n` items.

At every time step, we scan all remaining items to find the item with maximum effective density.

In the worst case:

- First selection: `n` comparisons
- Second selection: `n-1` comparisons
- Third selection: `n-2` comparisons
- ...
- Last selection: `1` comparison

Therefore:

\[
T(n)=n+(n-1)+(n-2)+\cdots+1
\]

\[
T(n)=\frac{n(n+1)}{2}
\]

Thus:

\[
\boxed{T(n)=O(n^2)}
\]

### Space Complexity

We store `n` items in an array.

Therefore:

\[
\boxed{S(n)=O(n)}
\]

---

## 9. Complexity Summary

| Operation | Complexity |
|---|---:|
| Input | `O(n)` |
| Find maximum effective density | `O(n)` per iteration |
| All iterations | `O(n²)` |
| Space | `O(n)` |

### Final Complexity

\[
\boxed{\text{Time Complexity} = O(n^2)}
\]

\[
\boxed{\text{Space Complexity} = O(n)}
\]

---

## 10. Key Points

- This is a variation of the **Fractional Knapsack** problem.
- The value density changes with time.
- Effective density is:

\[
\boxed{\frac{v_i}{w_i}-\lambda_i t}
\]

- At every time, choose the unused item with the highest effective density.
- A complete item is taken if it fits.
- Otherwise, take a fraction of the item.
- Repeat until the knapsack is full.
- Time complexity is `O(n²)`.
- Space complexity is `O(n)`.
