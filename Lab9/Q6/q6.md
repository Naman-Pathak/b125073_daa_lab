Reorganise String with K-Distance Apart
1. Problem Statement
Given a string S and an integer K, rearrange the characters of S
so that any two occurrences of the same character are at least K
positions apart.
- If a valid rearrangement exists, return or display one.
- If no valid rearrangement exists, the result is an empty string.
- Every character must be used exactly as many times as it occurs in
  the original string.
Example
- Input: S = "aaabc", K = 2
- One valid output: "abaca"
- Explanation: the two a characters are not adjacent; their
  positions are 0, 2, and 4, so repeated occurrences are at least 2
  positions apart.
For K = 1, there is no separation restriction, so the original string
is already valid. For an empty string, the result is also empty.
2. Input Representation
For a C implementation, represent the input using:
1. A character array (string) S, such as "aaabc".
2. An integer K, such as 2.
The string length is n. The algorithm can use a frequency table to
count each character. For a simple C implementation, a table indexed by
character value is suitable when the input character set is fixed (for
example, ASCII).
3. Main Idea
Use a greedy strategy with two data structures:
- Frequency table: records how many times each character remains
  to be placed.
- Max-heap / priority queue: makes the currently available
  character with the highest remaining frequency easy to select.
- Cooldown queue: temporarily holds a character after it is
  placed, until it is allowed to appear again.
The greedy choice is to place the available character that has the
highest remaining frequency. This helps avoid leaving a frequently
occurring character until the end, when there may be too few positions
to separate its occurrences.
4. Algorithm Approach
1. Count the frequency of every character in S.
2. Insert each character with a non-zero frequency into a max-heap. The
   character with the largest remaining frequency should have the
   highest priority.
3. Create an empty cooldown queue. Each entry stores a character, its
   remaining frequency, and the earliest output position at which it
   may be used again.
4. Process the output positions from left to right:
   - Release from the cooldown queue every character whose allowed
     position has been reached, and insert it back into the max-heap
     if its remaining frequency is greater than zero.
   - If the max-heap is empty while characters still need to be
     placed, no valid arrangement can be completed. Report an empty
     string.
   - Otherwise, remove the character with the largest remaining
     frequency from the max-heap and append it to the result.
   - Decrease that character's remaining frequency.
   - If it still has occurrences left, place it in the cooldown queue
     with earliest allowed position equal to the current position
     plus K.
5. If all n positions are filled, the result is a valid
   rearrangement.
Important: A character placed at index i cannot be used again
before index i + K. This is what guarantees a distance of at least K
between equal characters.
5. Dry Run
Input: S = "aaabc", K = 2
Initial frequencies: a: 3, b: 1, c: 1.
Output position Available choice   Action                                         Result so far
              0 `a`                Place `a`; it can next be used at position 2   `a`
              1 `b`                Place `b`                                      `ab`
              2 `a`                `a` becomes available; place it                `aba`
              3 `c`                Place `c`                                      `abac`
              4 `a`                Place the final `a`                            `abaca`
Output: "abaca"
The occurrences of a are at positions 0, 2, and 4. The output uses
every input character and satisfies the distance requirement.
6. When Is a Solution Impossible?
If characters remain but the max-heap is empty at a position, all
remaining characters are still in cooldown. There is no legal character
that can fill the current position, so the algorithm reports failure and
returns an empty string.
For example, with S = "aaaaab" and K = 3, there are too many
occurrences of a to separate them sufficiently. The algorithm will get
stuck before placing all characters and report no solution.
The greedy algorithm's failure check is important: it validates whether
the arrangement can actually be completed rather than assuming every
input has a solution.
7. Correctness Intuition
- Distance condition: After placing a character at position i,
  the algorithm keeps it out of the max-heap until position i + K.
  Therefore, the same character cannot be placed within fewer than K
  positions of its previous occurrence.
- Character counts: Each placement reduces exactly one character's
  remaining frequency by one. No character is added or removed from
  the input's total count, so a successful result contains exactly the
  original multiset of characters.
- Failure detection: If characters remain but no character is
  available, the next position cannot be filled without breaking the
  distance rule. Hence the algorithm correctly reports failure for
  that attempted arrangement.
- Completion: If all n positions are filled, the result has the
  correct length, preserves all character counts, and satisfies the
  distance condition.
8. Complexity Analysis
Let:
- n = length of the input string.
- σ = number of distinct characters in the input alphabet.
Assume the max-heap stores at most σ distinct characters and each heap
insertion or removal costs O(log σ).
Time Complexity
- Counting character frequencies: O(n).
- Building the max-heap: O(σ) with heap construction, or
  O(σ log σ) if characters are inserted one by one.
- Processing the string: each character is placed once, and each
  distinct character may be removed from and inserted into the heap
  multiple times, but only in proportion to its occurrences. The total
  heap work is O(n log σ).
- Cooldown queue operations take O(n) total.
Overall time complexity: O(n log σ) (using efficient heap
construction and standard heap operations). If the character set is
fixed, such as ASCII, σ is bounded by a constant, so this becomes
O(n).
Space Complexity
- Frequency table and heap: O(σ).
- Cooldown queue: at most O(min(n, σK)) in a straightforward
  implementation, and no more than O(n) in the worst case.
- Output string: O(n).
Including the output, the overall space complexity is O(n + σ),
which is O(n) for a fixed character alphabet. If output storage is
excluded, auxiliary space is at most O(n + σ) for this queue-based
design.

10. Conclusion
The problem can be approached using a greedy max-heap and a cooldown
queue. Selecting the most frequent currently available character helps
distribute repeated characters, while the cooldown queue enforces the
minimum distance. The algorithm runs in O(n log σ) time and uses
O(n + σ) space when the output is included. A C program can validate
it using the test cases and checks described above.
