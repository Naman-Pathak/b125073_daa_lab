# Minimum Initial Fuel (Reverse Greedy)

## Problem Statement

A vehicle needs to reach a target distance `D`, starting with an initial amount of fuel `F`.

Along the route, there are `n` fuel stations. Each station is represented by:

```text
(di, fi)
```

where:

- `di` = distance of the station from the starting point
- `fi` = amount of fuel available at that station

The vehicle consumes **1 unit of fuel for every 1 unit of distance**.

The objective is to determine the **minimum number of refuelling stops required to reach the target `D`**.

If the target cannot be reached, report that it is impossible.

---

## Example

Suppose:

```text
D = 25
F = 10
```

and the stations are:

| Station | Distance | Fuel |
|---|---:|---:|
| S1 | 5 | 5 |
| S2 | 10 | 10 |
| S3 | 15 | 7 |
| S4 | 20 | 8 |

Initially, the vehicle can travel:

```text
0 → 10
```

because it starts with `10` units of fuel.

Among the reachable stations, we choose the station that provides the maximum amount of fuel.

The process eventually allows the vehicle to reach:

```text
10 → 20 → 28
```

Since `28 >= 25`, the target is reached.

Therefore:

```text
Minimum number of stops = 2
```

---

# Greedy Approach

The main idea is:

> Whenever additional fuel is required, choose the reachable station with the maximum amount of fuel.

Why?

Suppose the vehicle can currently reach distance `R`.

If several previously reachable stations are available with fuel:

```text
5, 7, 10, 8
```

and we make one refuelling stop, selecting `10` gives:

```text
R + 10
```

which is at least as far as selecting any other station.

Therefore, the maximum-fuel station gives the greatest possible extension of our reachable distance using one additional stop.

This helps minimize the total number of stops.

---

# Why a Max Heap?

We need to repeatedly find the station having the **maximum fuel** among the stations that are currently reachable.

Searching through all stations every time would take `O(n)` per selection.

Instead, we use a **max heap**.

A max heap allows us to:

- Insert a station in `O(log n)`
- Get/remove the maximum fuel in `O(log n)`

Therefore, the greedy selection becomes efficient.

---

# Input Representation

We represent every station using a structure:

```c
typedef struct {
    int distance;
    int fuel;
} Station;
```

For example:

```text
Station 1 → distance = 5,  fuel = 5
Station 2 → distance = 10, fuel = 10
Station 3 → distance = 15, fuel = 7
```

All stations are stored in an array.

# Algorithm

## Step 1: Sort the Stations

Sort all stations according to their distance from the starting point.

Example:

```text
(5,5)
(10,10)
(15,7)
(20,8)
```

Sorting makes it easy to determine which stations are currently reachable.

---

## Step 2: Initialize

Set:

```text
reach = F
stops = 0
```

Here, `reach` represents the maximum distance the vehicle can currently travel.

---

## Step 3: Add Reachable Stations

While there are stations whose distance is less than or equal to `reach`, insert their fuel values into the max heap.

Condition:

```text
station.distance <= reach
```

---

## Step 4: Check Whether the Destination Is Reached

If:

```text
reach >= D
```

then the destination has been reached.

Return `stops`.

---

## Step 5: Refuel from the Best Station

If the destination has not been reached:

- Remove the maximum fuel value from the max heap.
- Add it to `reach`.
- Increment `stops`.

```text
reach = reach + maximumFuel
stops++
```

---

## Step 6: Detect Impossible Cases

If:

```text
reach < D
```

and the max heap is empty, there is no reachable station from which additional fuel can be obtained.

Therefore, the destination is impossible to reach.

Return:

```text
-1
```

---

# Pseudocode

```text
MinimumStops(D, F, stations):

    Sort stations by distance

    reach = F
    stops = 0
    maxHeap = empty
    index = 0

    while reach < D:

        while index < n
              and stations[index].distance <= reach:

            insert stations[index].fuel into maxHeap
            index++

        if maxHeap is empty:
            return -1

        fuel = remove maximum from maxHeap

        reach = reach + fuel
        stops++

    return stops
```

# Correctness of the Greedy Approach

Let the current reachable distance be `R`.

Suppose several reachable stations have fuel amounts:

```text
f1, f2, ..., fk
```

Let:

```text
fmax = maximum(f1, f2, ..., fk)
```

If one additional stop is allowed, choosing `fmax` gives:

```text
R + fmax
```

For every other station `fi`:

```text
R + fi <= R + fmax
```

Therefore, choosing the maximum-fuel station always produces the maximum possible reachable distance after the same number of stops.

So, if a solution using `k` stops exists, the greedy algorithm can reach at least as far as any other solution using `k` stops.

Consequently, when the greedy algorithm reaches `D`, the number of stops is minimum.

# Complexity Analysis

Let `n` be the number of fuel stations.

## Sorting

The stations are sorted by distance.

```text
O(n log n)
```

## Heap Insertions

Every station is inserted into the max heap at most once.

Each insertion costs:

```text
O(log n)
```

Therefore:

```text
O(n log n)
```

## Heap Deletions

Every station can be selected at most once.

Each deletion from the max heap costs:

```text
O(log n)
```

Therefore:

```text
O(n log n)
```

## Total Time Complexity

Combining all operations:

```text
O(n log n) + O(n log n) + O(n log n)
```

Therefore:

```text
O(n log n)
```

### Time Complexity

**`O(n log n)`**

### Space Complexity

The station array requires:

```text
O(n)
```

The max heap requires:

```text
O(n)
```

Therefore:

### Space Complexity

**`O(n)`**

# Key Takeaways

1. This is a **Greedy Algorithm** problem.
2. Sort stations according to their distance.
3. Keep all currently reachable stations in a **Max Heap**.
4. Whenever more fuel is required, choose the station with the **maximum fuel**.
5. Continue until the target distance is reached.
6. If no reachable station is available and the target has not been reached, the journey is impossible.
7. The overall complexity is:

```text
Time  = O(n log n)
Space = O(n)
```
