Minimise Deviation in an Array --- Two-Way Greedy with Max-Heap
1. Problem Statement
Given an array A of positive integers, the allowed operations are:
- If an element is odd, multiply it by 2.
- If an element is even, divide it by 2.
The deviation of the array is:
Deviation = maximum element − minimum element
The goal is to perform zero or more allowed operations so that the
deviation is as small as possible.
2. Input Representation
For a C implementation, represent the input using:
- An integer n, the number of elements.
- An integer array A containing the n positive integers.
Example:
- Input array: [1, 2, 3, 4]
- Number of elements: n = 4
Use a sufficiently wide integer type (such as long long in C) if input
values may be large, because doubling an odd number can overflow a
smaller integer type.
3. Key Observation
Every number can be transformed into a limited set of useful values:
- An odd number can be doubled once to become even.
- Once a number is even, it can be divided by 2 repeatedly until it
  becomes odd.
- In an optimal solution, it is useful to start by doubling every odd
  number. This makes every starting value even.
- After that, repeatedly divide the current maximum even value by
  2. Once a value becomes odd, it cannot be doubled again in this
  phase, so it is treated as fixed.
This gives the standard greedy strategy: keep the largest current value
in a max-heap, and always reduce that maximum when it is even.
4. Algorithm Approach
Use a max-heap to retrieve the largest current element efficiently.
1. Read n and the array A.
2. For every element:
   - If it is odd, multiply it by 2.
   - Insert the resulting value into the max-heap.
3. Find the minimum value among these initial transformed values and
   store it as currentMin.
4. Compute the initial deviation: heap maximum − currentMin. Store it
   as bestDeviation.
5. Repeat:
   - Remove the maximum value x from the max-heap.
   - Update the best deviation using x − currentMin.
   - If x is odd, stop. It cannot be reduced further using the
     permitted divide-by-two operation, and further progress by
     reducing the maximum is impossible.
   - Otherwise, divide x by 2.
   - Update currentMin if the reduced value is smaller.
   - Insert the reduced value back into the max-heap.
   - Update bestDeviation using the current maximum minus
     currentMin.
6. Output bestDeviation.
Why a max-heap? The maximum element determines the upper end of the
deviation. Reducing the current maximum is the useful greedy move, and a
max-heap makes that element available in O(log n) time.
5. Dry Run
Input: A = [1, 2, 3, 4]
Step 1: Make every odd number even
- 1 → 2
- 2 → 2
- 3 → 6
- 4 → 4
Transformed array: [2, 2, 6, 4]
Initial minimum = 2, maximum = 6, deviation = 6 − 2 = 4.
Step 2: Repeatedly reduce the maximum
  Current values   Maximum removed Action         Current minimum  Best deviation
  (conceptually)                                                             seen
  [2, 2, 6, 4]                 6 6 / 2 = 3;                 2               4
                                   insert 3                       
  [2, 2, 4, 3]                 4 4 / 2 = 2;                 2               2
                                   insert 2                       
  [2, 2, 3, 2]                 3 Odd, so stop                 2               1
The smallest deviation encountered is 3 − 2 = 1.
Output: 1
One optimal resulting array is [2, 2, 3, 2], whose maximum is 3 and
minimum is 2.
6. Correctness Intuition
- Useful starting values: Doubling each odd input once is valid
  and places all values in an even state from which they can be
  repeatedly halved. This standard normalization considers the useful
  upward move for odd numbers before the greedy reduction phase.
- Greedy choice: For the current set of values, the maximum is the
  only value whose reduction can lower the current maximum. Reducing a
  smaller value cannot improve the maximum and may only leave the
  deviation unchanged or worsen it.
- Track the minimum: Whenever a maximum is halved, the minimum can
  stay the same or decrease. Maintaining currentMin ensures the
  deviation is calculated correctly after each change.
- Stopping rule: Once the current maximum is odd, it cannot be
  halved using the allowed operation. All other values are no larger,
  so reducing another value cannot lower the maximum. Therefore, no
  further useful reduction of the maximum is possible.
- Best answer: The minimum deviation is the smallest deviation
  observed throughout the sequence, not necessarily the final
  deviation.
7. Complexity Analysis
Let n be the number of array elements and let M be the largest value
after initially doubling odd elements.
Time Complexity
- Normalizing the values and finding the initial minimum: O(n).
- Building a max-heap: O(n) with bottom-up heap construction, or
  O(n log n) if inserting each element individually.
- Each heap iteration removes one maximum and, if it is even, inserts
  its half. Each value can be halved only a logarithmic number of
  times before becoming odd. Across all n values, the number of
  iterations is O(n log M).
- Each heap removal/insertion costs O(log n).
Therefore, the overall time complexity is:
O(n log M log n), using efficient heap construction.
Here, M is the maximum normalized value. Equivalently, the number of
halving steps per value is proportional to the number of bits in the
integer.
Space Complexity
- Max-heap stores n values: O(n).
- The input array, if stored separately, uses O(n) space.
Therefore, total space complexity is O(n).
8. Validation Plan for a C Program
Test the implementation using cases such as:
  Test   Input array            Expected minimum deviation
  1      [1, 2, 3, 4]                                1
  2      [4, 1, 5, 20, 3]                            3
  3      [2, 10, 8]                                  3
  4      [1]                                         0
  5      [2, 2, 2]                                   0
  6      [3, 5, 7]                                   1
For each test:
1. Check that the program returns a non-negative deviation.
2. Confirm the reported deviation is the difference between the maximum
   and minimum of a reachable array state.
3. For small arrays, validate optimality by enumerating reachable
   values for each element and comparing the possible minimum
   deviations.
4. Include boundary tests with large positive integers to check for
   overflow when odd values are doubled.
9. Conclusion
The problem is solved using a greedy max-heap approach. First, double
all odd elements. Then repeatedly halve the current maximum while it is
even, updating the minimum and recording the smallest deviation seen.
The algorithm has O(n log M log n) time complexity and O(n)
space complexity.
