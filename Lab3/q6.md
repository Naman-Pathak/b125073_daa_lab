Pseudocode
SELECTION-SORT(A)


for i = 1 to n - 1


    minIndex = i


    for j = i + 1 to n


        if A[j] < A[minIndex]


            minIndex = j


    exchange A[i] with A[minIndex]
Loop Invariant

The loop invariant is:

At the beginning of each iteration i, the subarray A[1...i−1] contains the i−1 smallest elements of the array in sorted order.

For example:

Before iteration 1:
[ ? ? ? ? ? ]


Before iteration 2:
[ smallest ? ? ? ? ]


Before iteration 3:
[ smallest 2nd-smallest ? ? ? ]


Before iteration 4:
[ smallest 2nd 3rd ? ? ]
1. Initialization

Before the first iteration:

i=1

The subarray:

A[1...0]

is empty.

An empty array is already sorted.

Therefore, the loop invariant is true.

2. Maintenance

During iteration i, we search:

A[i...n]

and find its smallest element.

We exchange this element with A[i].

Therefore, after the exchange:

A[i]

contains the i
th
 smallest element.

Hence:

A[1...i]

is sorted.

Therefore, the invariant remains true.

3. Termination

The loop stops after:

i=n−1

At this point:

A[1...n−1]

contains the first n−1 smallest elements in sorted order.

Only one element remains at A[n].

Since it must be the largest element, the entire array is sorted.

Therefore the algorithm is correct.

Why only n−1 iterations?

We don't need to process the last element.

After finding and placing the smallest n−1 elements, the final element automatically has to be the largest.

For example:

[2, 5, 1, 4, 3]


After 1st:
[1, 5, 2, 4, 3]


After 2nd:
[1, 2, 5, 4, 3]


After 3rd:
[1, 2, 3, 4, 5]


After 4th:
[1, 2, 3, 4, 5]

No fifth iteration is required.
